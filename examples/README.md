# نمونه‌های اجرای واقعی

این فایل‌ها State ثبت‌شدهٔ اجراهای واقعی در ۹ اکتبر ۲۰۲۶ هستند. کلید API در آن‌ها وجود ندارد. نام نودها، تغییر State و نوع بررسی در هر فایل دیده می‌شود.

این پوشه برای مشاهدهٔ شواهد اجرای ثبت‌شده است. برای ارائهٔ فعلی از [ترتیب نهایی دمو](../DEMO.md) استفاده کنید و برای نتیجهٔ تست‌های محلی [TESTING.md](../TESTING.md) را ببینید.

| فایل | مدل این اجرا | نتیجه |
|---|---|---|
| [problem-state.json](problem-state.json) | `gpt-4o-mini` | مشتق `x^3 + 2*x` برابر `3*x^2 + 2`؛ `answered` و `symbolically_checked` |
| [concept-state.json](concept-state.json) | `gpt-4.1-mini` | توضیح شهودی انتگرال با انباشت مسافت؛ `answered` و `model_reviewed` |
| [clarification-state.json](clarification-state.json) | `gpt-4o-mini` | درخواست بدون معادله؛ سؤال تکمیلی و `needs_clarification` |

متن این snapshotها همان خروجی ثبت‌شده است و برای شبیه کردنشان به نسخهٔ فعلی بازنویسی نشده‌اند. مرحلهٔ `finalize` در نسخهٔ فعلی، شماره‌های اضافهٔ نوشته‌شده توسط مدل را پیش از ساخت متن نهایی حذف می‌کند. `terminal.py` رنگ و تأکید را فقط هنگام نمایش اضافه می‌کند؛ JSON و State به قالب رنگی ترمینال تبدیل نمی‌شوند.

## مشاهده و ثبت اجرای تازه

از داخل پوشهٔ اصلی پروژه اجرا کنید:

```powershell
.\.venv\Scripts\python.exe cli.py
```

سپس داخل گفت‌وگو، هر خط را پس از پایان خط قبلی وارد کنید:

```text
/trace on
Differentiate x^3 + 2*x step by step.
/state
/save demo/output/session.json
/exit
```

فایل تازه در `demo/output` ذخیره می‌شود و وارد Git نمی‌شود. `history` در آن مربوط به پیش از نوبت جاری و `trace` مربوط به همان نوبت است. متن پاسخ و تعداد مراحل یا اصلاح‌ها ممکن است بین اجراها متفاوت باشند. رنگ سبز پاسخ به‌تنهایی نشان‌دهندهٔ بررسی مستقل نیست؛ برای تشخیص نوع بررسی، فیلد `verification` را بخوانید.
