# تمرین چهارم — Complex Mathematics Tutor

مدرس ریاضی مایلو، با **LangGraph**، State مشخص، نودهای مستقل و ارتباط از طریق CLI. کاربر می‌تواند مفهوم ریاضی بپرسد، مسئله حل کند، سطح توضیح را تغییر دهد و اجرای گراف را ببیند.

گراف مرجع بخش ریاضی در [ریپوی تمرین سوم](https://github.com/mohsenalipour/starcoach-hw03-agent-architecture) و [ARCHITECTURE.md](ARCHITECTURE.md) مشخص شده و همان گراف در `agent.py` پیاده‌سازی شده است. فایل `graph.mmd` از خود گراف اجراشونده تولید می‌شود.

برای ضبط یا ارائه، [راهنمای دمو](DEMO.md) شامل سناریوی آمادهٔ مفهومی، حل مسئله، شفاف‌سازی و روش استفاده از فارسی بدون تایپ در PowerShell است.

## اجرای سریع

پروژه را دریافت کنید و وارد پوشهٔ آن شوید. در PowerShell:

```powershell
git clone https://github.com/mohsenalipour/starcoach-hw04-math-tutor.git
cd starcoach-hw04-math-tutor
.\setup.ps1
# Set the API key in .env before the first run.
.\run.ps1
```

با وارد کردن سؤال گفت‌وگو شروع می‌شود. مثال:

```text
You> مشتق را مثل یک معلم برای کسی که حسابان بلد نیست توضیح بده
You> حالا مشتق x^3 + 2*x را مرحله‌به‌مرحله حساب کن
You> /trace
You> /level advanced
You> چرا این روش درست است؟
You> /state
You> /exit
```

اگر اجرای فایل PowerShell در ترمینال مجاز نیست، مستقیماً Python را اجرا کنید:

```powershell
.\.venv\Scripts\python.exe cli.py
```

## نصب روی سیستم دیگر

Python 3.10 یا جدیدتر لازم است؛ روی Python 3.14 تست شده است.

```powershell
.\setup.ps1
```

سپس در `.env` مقدار `OPENAI_API_KEY`، `OPENAI_MODEL` و در صورت نیاز `OPENAI_BASE_URL` را تنظیم کنید. مثال اولیه برای AvalAI است. برای OpenAI مستقیم، مقدار `OPENAI_BASE_URL` را خالی بگذارید. برای Metis نیز سه متغیر `METIS_API_KEY`، `METIS_BASE_URL` و `METIS_CHAT_MODEL` پشتیبانی می‌شود؛ وجود کلید Metis آن را فعال می‌کند.

نصب دستی و اجرای مستقل از PowerShell:

```text
python -m venv .venv
# Windows:
.venv\Scripts\python.exe -m pip install -r requirements.txt
# Linux/macOS:
.venv/bin/python -m pip install -r requirements.txt
```

کپی `.env.example` به `.env` و تنظیم کلید برای نصب دستی لازم است. فایل تنظیمات به‌طور پیش‌فرض کنار `cli.py` خوانده می‌شود؛ متغیرهای محیطی موجود اولویت دارند. با `--env-file` می‌توان فایل دیگری را انتخاب کرد.

## اجرای یک سؤال

```powershell
.\run.ps1 -q 'مشتق x^3 + 2*x را حساب کن' --level beginner --language fa --trace
.\run.ps1 -q 'Solve 2*x + 3 = 7 step by step' --language en
.\run.ps1 -q 'انتگرال x از صفر تا دو چقدر است؟' --json --state-file session.json
.\run.ps1 --graph
.\run.ps1 --input-file .\demo\problem-fa.txt --language fa --html .\demo\output\answer.html
```

`--trace` نام نودها را هنگام اجرا و مسیر نهایی را در stderr نمایش می‌دهد. `--json` خروجی کامل State را در stdout می‌نویسد و برای حالت تک‌سؤال است. `--graph` بدون اتصال به مدل یا کلید API کار می‌کند.

`--input-file` سؤال را از فایل UTF-8 با یا بدون BOM می‌خواند. `--html` گزارش خوانای راست‌به‌چپ یا چپ‌به‌راست از آخرین پاسخ، مسیر و State ذخیره می‌کند. پوشهٔ خروجی باید موجود باشد؛ پوشهٔ `demo/output` آماده و خروجی‌هایش از Git خارج هستند. در گفت‌وگوی تعاملی، `--html` بعد از هر نوبت همان فایل را به‌روز می‌کند.

## فرمان‌های گفت‌وگو

| فرمان | عملکرد |
|---|---|
| `/level auto` | تشخیص سطح از متن و سابقه؛ پیش‌فرض مبتدی |
| `/level beginner` | توضیح شهودی، تعریف نمادها و مثال روزمره |
| `/level intermediate` | روش حل و اتصال شهود به فرمول |
| `/level advanced` | تعریف دقیق، فرض‌ها و استدلال فنی |
| `/language auto`، `/language fa`، `/language en` | انتخاب زبان |
| `/trace` | مسیر نودهای آخرین سؤال و نوع بررسی پاسخ |
| `/trace on`، `/trace off` | نمایش یا خاموش کردن پیشرفت نودها |
| `/state` | State آخرین اجرا به شکل JSON |
| `/save session.json` | ذخیرهٔ State آخرین اجرا |
| `/file question.txt` | خواندن سؤال از فایل UTF-8 در همین گفت‌وگو |
| `/html report.html` | ذخیرهٔ آخرین نتیجه در گزارش HTML قابل نمایش در مرورگر |
| `/graph` | گراف واقعی برنامه به صورت Mermaid |
| `/new` | پاک کردن سابقه و سؤال معلق؛ حفظ تنظیم سطح و زبان |
| `/help` | راهنما |
| `/exit` یا EOF | خروج |

در حالت `auto` سؤال فارسی پاسخ فارسی می‌گیرد. برای توضیح فارسی دربارهٔ عبارتی مانند `x^2` می‌توان `/language fa` را انتخاب کرد. نمایش چیدمان راست‌به‌چپ به ترمینال وابسته است. برای فارسی از فایل ورودی و گزارش HTML استفاده کنید؛ برای نمایش همهٔ تعامل‌ها در ترمینال، زبان انگلیسی در دسترس است. گزارش HTML فقط خروجی را نمایش می‌دهد و رابط تعامل با ایجنت CLI است.

## بررسی پاسخ و مدیریت خطا

برای همهٔ پاسخ‌ها، نود `review_answer` درستی، وضوح، ارتباط با سؤال و تناسب سطح را بررسی می‌کند. برای مسئله‌های قابل پشتیبانی، SymPy نیز محاسبه را مستقل انجام می‌دهد؛ نتیجهٔ اشتباه حتی با تأیید مدل به مسیر اصلاح می‌رود. نود اصلاح به‌طور پیش‌فرض فقط یک بار اجرا می‌شود. اگر پاسخ همچنان تأیید نشود، برنامه نتیجهٔ نامطمئن را به عنوان پاسخ نهایی منتشر نمی‌کند و درخواست دقیق‌تر شدن سؤال می‌دهد.

ابزار محلی مشتق، انتگرال با کران ثابت یا بدون کران، معادلهٔ چندجمله‌ای تک‌متغیره روی اعداد حقیقی، ساده‌سازی و دترمینان ماتریس عددی تا ۴×۴ را پشتیبانی می‌کند. حدود متغیر، معادلات پیچیده‌تر و مسائل خارج از این محدوده فقط با بازبینی مدل بررسی می‌شوند. وضعیت `symbolically_checked` یعنی نتیجهٔ نهایی با ابزار مقایسه شده؛ `reviewed_with_tool` یعنی محاسبه موجود است ولی تطبیق ماشینی عبارت نهایی ممکن نبوده؛ `model_reviewed` یعنی فقط مدل بازبینی کرده است. این بررسی‌ها اثبات عمومی درستی همهٔ پاسخ‌ها نیستند.

عبارت‌ها با AST محدود خوانده می‌شوند و `eval` یا پارس آزاد SymPy روی ورودی اجرا نمی‌شود. محاسبه در یک فرایند جدا با مهلت ۶ ثانیه انجام می‌شود. پاسخ هر نود مدل با Pydantic اعتبارسنجی می‌شود؛ پاسخ JSON نامعتبر حداکثر یک بار اصلاح می‌شود. قطع شبکه، کلید نامعتبر، محدودیت اعتبار و پایان مهلت درخواست پیام قابل‌فهم می‌دهند. در صورت خطای مدل، سابقهٔ گفت‌وگو دست‌نخورده باقی می‌ماند.

حافظه به ۱۲ پیام قبلی محدود است و در RAM نگه داشته می‌شود. ذخیرهٔ State فقط با فرمان یا گزینهٔ صریح انجام می‌شود؛ پس از بستن برنامه، گفت‌وگو خودکار بازیابی نمی‌شود. کلید API وارد State، trace یا فایل تحویل نمی‌شود. سؤال‌ها و بخشی از سابقه برای ارائه‌دهندهٔ مدل انتخاب‌شده ارسال می‌شوند.

## تست و تحویل

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

تست‌ها مسیر مفهومی و حل مسئله، شفاف‌سازی، اصلاح محدود، جلوگیری از تأیید جواب غلط، حافظهٔ چندنوبتی، ذخیرهٔ State، عملیات ریاضی، ورودی نامعتبر، خطاهای مدل و فرمان‌های CLI را بررسی می‌کنند. این تست‌ها به کلید API نیاز ندارند. شواهد اجرای واقعی در پوشهٔ `examples` قرار دارد.

فایل ZIP تحویل، کد و مستندات را دارد. `.env`، محیط مجازی و cache در آن قرار نمی‌گیرند. برای تحویل کلید API را ارسال نکنید.
